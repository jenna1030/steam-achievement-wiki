# 프로젝트 문서

README에는 프로젝트 소개, 실행 방법, 배포에 필요한 최소 정보를 둡니다.
세부 설계와 발표 자료는 아래 문서로 분리합니다.

| 문서 | 내용 |
| --- | --- |
| [프로젝트 README](../README.md) | 기능, 기술 스택, 실행·배포, 현재 한계 |
| [설계와 기술 선택](architecture.md) | 데이터 흐름, 상태 분리, 성능·안전 설계 |
| [발표 가이드](presentation-guide.md) | 발표 순서, 기획 대비 범위, 예상 질문 |

## 문서 관리 원칙

- 실제 코드에 없는 기능은 완료로 표현하지 않습니다.
- Steam에서 가져오는 데이터와 사용자 작성 데이터를 구분합니다.
- 테스트 수, 페이지 크기, 레이트 리밋처럼 변하기 쉬운 숫자는 코드 변경과 함께
  갱신합니다.
- 실행·환경변수·배포 절차는 README 한 곳에서 관리합니다.
- 발표 가이드는 구현 근거와 한계를 설명하는 용도로 사용하고 실행 설명을
  중복하지 않습니다.
